## What was built

All seven modules are small, deterministic, and zero-model-call. Pure
functions take explicit inputs (snapshots, fingerprints, injected runners)
and return typed records; nothing reads the clock, environment, or network
except the injected test/command runners the caller supplies.

1. **validation-policy.ts** (EP15/EP16): `deriveValidationIntents` (acceptance
   behavior + consumers/contracts/config/schema/security/isolation impact with
   a concise reason; exact failures are `targeted`), `orderValidationIntents`
   (exact failures first, then affected, then targeted, then final),
   `resolveValidationMandates` (default full suite belongs to the final
   candidate; explicit source/project gates retained; same-id scope conflicts
   surfaced, never silently picked), `resolveInheritedBaselineFailures`
   (explicit authorized disposition required; never auto-introduced, never an
   auto-waiver; packet-required waivers rejected), `partitionPacketVsFinal`
   (packet-required must pass; final-gate stays visibly pending without
   forcing a premature full suite).
2. **validation-observation.ts** (EP17/EP18, OA-14): `createValidationObservation`
   (command/method, revision + uncommitted-content digest when dirty, four
   fingerprints, outcome/counts, inspectable artifacts; unsupported output is
   `unknown`; unexplained skips rejected), `assessObservationForAcceptance`
   (fails closed on zero selection, no relevant assertions, stale snapshot or
   dirty hash, substituted artifact, wrong environment/capability, prose
   claim, and RG-2 failing-command-for-required-GREEN), `recordRedGreenPair`
   (same intent, harness failures excluded), `recordFaultInjection` (test
   retained, byte-exact restore, guard isolation, protected-evidence mutation
   refused, redundant same-defect mutation refused), `recordFlakyIsolation`
   (only failing tests, once, same revision+environment).
3. **evidence-applicability.ts** (EP19/EP20, OA-2/EP35): `decideApplicability`
   (reusable/invalidated/unknown with proof; changed behavior or any
   mismatched dimension invalidates affected + downstream; missing info
   yields bounded investigation + relevant expansion, never unconditional
   reuse or blind full rerun), `toFrozenDecision` (unknown cannot convert),
   `propagateInvalidation` (transitive downstream invalidation; independent
   checks untouched), `decideUnverifiedClaim` (mechanical command/exit/
   revision/artifact match; residue labelled reviewer judgement).
4. **change-risk.ts** (OA-4/EP38): pure deterministic `assessChangeRisk` over
   the six signals as exported constants (`ChangeRiskLevel`,
   distinct from `risk-policy.ts` per G-8). Author tier from an OA-16
   snapshot else the recorded default (lower tier raises risk); shared kernel
   surface as a named 27-file set; source-without-test; >1 attempt;
   acceptedFailures waiver; size in files+lines. Thresholds measured against
   the fourteen P6.5 packet commits (table below); all three acceptance
   conditions hold, so thresholds are accepted (not forced, not an owner
   decision).
5. **affected-tests.ts** (OA-12/EP46): `computeAffectedTests` ladder
   (impact tool → LSP references → module graph → full suite) with injected
   rungs; widening triggers (build config, lockfile, shared header,
   generated code, unknown file type) skip to at least the module graph;
   not-configured/failing/`unsupported_language` rungs fail down (never an
   empty selection); rung recorded. Module-graph parsers for npm workspaces,
   .NET (csproj/solution refs), CMake targets, Cargo crates, Go packages, and
   Maven/Gradle modules.
6. **test-report-readers.ts** (OA-13/EP47): JUnit XML and TRX readers via a
   small safe tag/attribute scanner (no new dependency, no entity expansion,
   size-bounded). Missing/empty/unreadable/inconsistent reports yield
   `unknown`, never `passed`; zero-selected is `unknown`.
7. **mutation-probe.ts** (OA-11/EP45): `runBreakItProbe` library with
   injectable command runner + filesystem (not wired into the scheduler).
   Ladder: configured project tool (Stryker/Stryker.NET/PIT/mutmut/
   cargo-mutants/Mull) → built-in token mutator (comparisons, booleans,
   +/-, &&/|| and and/or) on changed lines only with a comment- and
   string-aware lexer per family (C + Python, multi-line carry) →
   `not_available`. Disposable copy; non-building mutants discarded; count
   and time caps with partial coverage recorded; survivors never block;
   rung recorded.
8. **Store extensions** (T1-frozen shape: store + inspect observations/
   applicability): `evidence-store.ts` gains additive `StoredValidationObservation`,
   `StoredApplicabilityDecision`, and `ExtendedEvidenceStore` (the existing
   `EvidenceStore` interface is untouched); `sqlite-evidence-store.ts`
   implements it with two new tables, idempotent recording, fail-closed body
   validation, and legacy-DB tolerance; `evidence-tools.ts` gains
   `createValidationEvidenceTools` (`inspect_validation_observations`,
   `inspect_applicability_decisions`), leaving `createEvidenceTools` output
   byte-identical.

## Design choices

- T1's frozen `ValidationIntent` / `ValidationObservation` /
  `EvidenceApplicabilityDecision` validators are the floor: every T5
  constructor calls them and adds the meaningful-observation guards on top.
  `unknown` applicability is a T5-level pending state (with investigation +
  expansion) because T1's decision vocabulary is reusable/invalidated only.
- Capability fingerprint and uncommitted-content digest ride alongside (not
  inside) the frozen observation: `MeaningfulObservation` wraps the T1 record
  with the extra fields, so frozen consumers keep compiling.
- RG-2 is enforced at two levels: the exit-code rule (failing command for a
  required passing test) and the verdict-citation rule via
  `assertSatisfiedVerdictsCiteGreenEvidence`, plus an explicit guard that an
  *accepted* RED still cannot discharge required GREEN.
- The affected-tests and mutation-probe rungs are injectable (no direct
  process/FS/LSP calls in the ladder core) so tests are deterministic and
  later tasks can bind the real runners.
- The XML readers scan only the tags they need with a bounded attribute
  regex; there is no general XML parser to become an XXE or billion-laughs
  surface.
