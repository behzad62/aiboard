## Deviations

- The synchronous commit is a wrapper in `build-runtime.ts`, not a change to `architect-tools.ts`. The tool still appends `project_doc.requested` and returns; the wrapper commits before that return reaches the model.
- The document tip is cleared when the canonical integration revision changes. A keep (`equal_to_tip` or `ancestor`) rewrites the task payload to the current canonical revision, so `advanceIntegrationRevision` is a no-op, the tip stays, and the idempotency key payload matches a retry. `latestIntegratedTaskSequence` updates only on that canonical advance, and only when `projectDocsPolicyVersion === 1`, so an unstamped replay does not grow a new field.
- A failed document commit runs `git reset --hard HEAD` and `git clean -fd` on the added paths before rethrowing.
- `project-docs.ts` does not import `node:fs` write APIs. `lstat` and `writeFile` stay in `integration-manager.ts`.
- `findIntegratedRevision` was left as its own log walk.
